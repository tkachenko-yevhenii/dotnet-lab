# dotnet-lab

Small experiments with .NET and C#.

I am a backend .NET developer. Here I try new .NET features, run benchmarks
and write short notes about what I learned. Every experiment is small and
runs on its own.

## How to run

Each experiment has its own folder and its own README with steps.
You need the .NET SDK that the experiment uses (usually .NET 10 and/or .NET 11).

```bash
cd 01-...
dotnet run -c Release
```

## Rules for this repo

- All numbers come from my own machine. Your results can be different.
- Code is simple on purpose. The goal is to learn, not to build a framework.
- Feedback and ideas are welcome. Open an issue.
